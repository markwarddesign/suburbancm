# Suburban CM Theme

## Description
This is a custom WordPress theme designed to provide a minimal and clean starting point for WordPress development.

## Installation
1. Download the theme files.
2. Upload the `suburbancm` folder to the `/wp-content/themes/` directory of your WordPress installation.
3. Go to the WordPress admin dashboard.
4. Navigate to Appearance > Themes.
5. Activate the "SuburbanCM".

## Usage
Once activated, you can start customizing the theme by editing the `style.css` and `index.php` files. You can add additional templates and styles as needed.
